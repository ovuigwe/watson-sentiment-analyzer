# AI-Powered Sentiment Analyzer

An AI-powered web application built with Python, Flask, and IBM Watson Natural Language Processing (NLP) to analyse the sentiment of text.

The application identifies whether a statement expresses positive, negative, or neutral sentiment and returns a corresponding confidence score.

## Features

- AI-powered sentiment analysis using IBM Watson NLP.
- Classification of positive, negative, and neutral sentiments.
- Multilingual sentiment analysis.
- Flask-based web interface.
- Input validation and error handling.
- Unit testing with Python unittest.
- Code quality verification using Pylint.

## Technologies Used

- Python 3.11
- Flask
- IBM Watson NLP
- Requests
- HTML
- JavaScript
- Bootstrap
- Pylint
- Unittest
